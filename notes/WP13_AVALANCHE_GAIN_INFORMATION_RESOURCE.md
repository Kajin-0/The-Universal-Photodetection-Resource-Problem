# WP13 — Avalanche gain as an information/resource layer

**Date:** 2026-08-20  
**Corrected:** 2026-08-20 after output-record audit

## Purpose

Stress-test active internal gain. Conventional APDs improve electrical amplitude and can overcome downstream electronics noise, but avalanche multiplication is stochastic and produces excess noise.

The central UPRP question is not whether gain improves ordinary SNR, but whether gain creates, preserves, or destroys **source information** under a specified accessible output record.

Main conclusions:

1. parameter-independent multiplication cannot increase Fisher information;
2. deterministic invertible gain preserves FI exactly;
3. **random gain alone need not reduce FI if individual primary-derived events remain resolved**;
4. avalanche excess noise becomes an FI penalty when gain randomness is combined with record coarse graining/overlap, dropout, dead time, timing jitter, or downstream noise;
5. physical gain also consumes bias/free-energy resources.

---

# 1. Exact data-processing theorem

Let `N` denote the complete primary photoelectron record generated by optical parameter `theta`, and let avalanche multiplication plus readout be a parameter-independent channel

\[
N\to Y.
\]

Then

\[
\boxed{F_Y(\theta)\le F_N(\theta).}
\]

Thus active electrical multiplication cannot create optical information that was absent from the primary carrier record.

**Status:** PROVED by classical FI data processing.

---

# 2. Deterministic gain is information-invariant

If

\[
Y=MN,
\qquad M\ne0
\]

with perfectly known deterministic gain and exact continuous readout, the map is invertible and

\[
\boxed{F_Y=F_N.}
\]

Hence deterministic gain changes electrical scale but not source information. It is useful only relative to later noise, quantization, or detection thresholds.

---

# 3. Resolved marked-point-process theorem — critical correction

Suppose primary photon/photoelectron events form a Poisson point process with rate `lambda(theta)`.

Each primary event independently produces one avalanche pulse with random positive mark `M_i` drawn from a `theta`-independent distribution, and assume:

- every primary event produces a resolvable pulse;
- pulse timestamps remain individually identifiable;
- no event is lost to dead time or thresholding.

Then the output is a **marked Poisson process** whose ground event process has exactly the same rate `lambda(theta)`.

The mark distribution is independent of `theta`, so it contributes zero score. Therefore the complete resolved event record obeys

\[
\boxed{F_{\rm resolved\ avalanche}=F_{\rm primary}.}
\]

Thus

\[
\boxed{
\text{stochastic gain by itself does not necessarily reduce source FI}.
}
\]

This is another output-record/coarse-graining effect.

---

# 4. Dropout/thinning immediately reduces FI

If each primary event produces a detectable avalanche pulse only with probability `p`, independently of `theta`, the visible event process is Poisson with rate

\[
p\lambda(\theta).
\]

For fractional rate modulation, the FI is reduced by exactly `p`:

\[
\boxed{\eta_I=p.}
\]

Thus zero-gain probability, threshold loss, or avalanche-trigger inefficiency is a genuine information loss even with perfectly resolved surviving events.

---

# 5. Compound-Poisson analog-charge model

If individual avalanche events are **not** retained and only total/integrated charge is observed, let

\[
N\sim{\rm Poisson}(\lambda),
\qquad
Q=\sum_{i=1}^{N}M_i.
\]

With

\[
\bar M=\mathbb E[M_i],
\qquad
F_M=\frac{\mathbb E[M_i^2]}{\bar M^2}\ge1,
\]

compound-Poisson moments are

\[
\boxed{\mathbb E[Q]=\lambda\bar M,}
\]

\[
\boxed{{\rm Var}(Q)=\lambda\bar M^2F_M.}
\]

The map from the resolved marked process to integrated charge is a coarse graining and can lose FI.

---

# 6. High-count linear-Gaussian information approximation

For weak fractional modulation

\[
\lambda(\theta)=\lambda_0(1+\theta),
\]

the primary Poisson FI is `lambda_0`.

In the high-count/linear-Gaussian approximation, with independent downstream electronics-noise variance `sigma_e^2`, the integrated-charge mean-channel FI gives

\[
\boxed{
\eta_I^{\rm analog}
\simeq
\frac1{
F_M+\sigma_e^2/(\lambda_0\bar M^2)
}.
}
\]

This expression applies to the specified **coarse-grained analog record**, not to the complete resolved avalanche point process.

The denominator separates:

- multiplication/excess-noise penalty created by analog coarse graining;
- downstream electronics noise referred through gain.

---

# 7. Standard McIntyre APD model

For electron-initiated multiplication in the local McIntyre model,

\[
\boxed{
F(M)=kM+(1-k)\left(2-\frac1M\right),
}
\]

where `k` is the hole/electron impact-ionization coefficient ratio in the conventional notation.

APD shot-noise theory uses the standard scaling

\[
S_I\propto M^2F(M).
\]

This is prior art.

Define

\[
A=\sigma_e^2/\lambda_0
\]

in primary-electron-count units. The analog Gaussian information approximation becomes

\[
\boxed{
\eta_I(M)
\simeq
\frac1{F(M)+A/M^2}.
}
\]

---

# 8. Exact optimal-gain equation in the analog Gaussian model

Minimize

\[
D(M)=F(M)+A/M^2.
\]

Then

\[
D'(M)=k+\frac{1-k}{M^2}-\frac{2A}{M^3}.
\]

An interior optimum satisfies

\[
\boxed{kM^3+(1-k)M-2A=0.}
\]

For `k>=0` this has at most one positive root. The physical optimum is the larger of unity and that root.

For ideal single-carrier McIntyre limit `k=0`,

\[
\boxed{M_*=2A}
\]

when that exceeds 1.

Thus gain is useful only until downstream electronics noise is no longer dominant; further gain can reduce analog-record information because `F(M)` grows.

---

# 9. High-gain limits are record dependent

For `k>0`, McIntyre `F(M)~kM` at high gain, so the **integrated analog Gaussian** information fraction tends toward zero after downstream noise becomes negligible.

For `k=0`, `F(M)->2`, giving an analog high-gain limit near one-half in that approximation.

Neither statement applies to a perfectly resolved marked event record, which can retain the full primary count FI if every event remains identifiable.

This record dependence is mandatory in UPRP.

---

# 10. Bias/pump free energy is independent of FI monotonicity

Data processing says gain cannot create source information; it does not make gain thermodynamically free.

Avalanche multiplication uses reverse-bias electrical free energy. A resource-complete active detector description should include:

- bias voltage/electric field;
- multiplication-region length/time;
- impact-ionization statistics;
- dissipated/bias power or free-energy throughput;
- timing/dead-time resources;
- downstream noise/quantization that gain is intended to overcome.

---

# 11. Resource-completeness statement

The correct active-gain layer is

\[
\boxed{
\text{gain statistics}
+\text{event resolvability/coarse graining}
+\text{dropout/dead time/timing jitter}
+\text{bias/free-energy resource}
+\text{downstream noise/quantization}.
}
\]

A scalar multiplication gain `M` or excess-noise factor `F(M)` alone is not an information-complete description.

---

# 12. Novelty boundary

Do not claim APD excess noise, McIntyre multiplication statistics, gain-bandwidth tradeoffs, or the usefulness of APD gain against amplifier noise as novel.

The UPRP-specific point is the output-record distinction: stochastic avalanche gain can be FI-neutral in a resolved marked point process yet FI-degrading after analog coarse graining.
