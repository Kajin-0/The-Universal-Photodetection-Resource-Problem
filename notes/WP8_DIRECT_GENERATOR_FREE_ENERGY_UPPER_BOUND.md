# WP8 — Direct generator-moment free-energy upper bound

**Date:** 2026-08-20

## Purpose

The first globally valid arbitrary-state free-energy QFI ceiling in `WP8_GLOBAL_FREE_ENERGY_UPPER_BOUND.md` used the relaxation

\[
D_0\to N_+(D_0)\to J_X.
\]

That route is rigorous but unnecessarily loose. Since displacement QFI is directly bounded by the translation-generator second moment, one can optimize `P^2` itself under the relative-entropy budget. That constrained expectation problem is exactly solvable by the Gibbs variational principle.

The result is a strictly more direct global upper envelope for arbitrary pointer states.

---

## 1. QFI is bounded by the generator second moment

For translation generated by `P`,

\[
J_X(\rho)\le4\operatorname{Var}_\rho(P)
\le4\langle P^2\rangle_\rho.
\]

Therefore

\[
J_F^{\max}(D_0,\vartheta)
\le
4\sup_{\rho:\,D(\rho\Vert\tau_\vartheta)\le D_0}
\langle P^2\rangle_\rho.
\]

Here

\[
\tau_\vartheta=(1-e^{-\vartheta})e^{-\vartheta N},
\qquad
\vartheta=\beta\hbar\omega_D.
\]

---

## 2. Exact relative-entropy dual for `P^2`

The Gibbs variational principle gives

\[
\boxed{
M_P(D_0,\vartheta)
\equiv
\sup_{D(\rho\Vert\tau)\le D_0}
\langle P^2\rangle
=
\inf_{0<s<\vartheta/2}
\frac{
D_0+\ln Z_P(s)
}{s},
}
\]

where

\[
Z_P(s)
=\operatorname{Tr}
\exp(\log\tau_\vartheta+sP^2).
\]

The normalizability boundary is `s < vartheta/2`.

The optimizing state for the **second-moment problem** is a squeezed thermal Gaussian state

\[
\rho_s
=Z_P(s)^{-1}
\exp(\log\tau+sP^2).
\]

This does **not** mean it globally maximizes SLD QFI; the parity counterexample proves otherwise. It only maximizes `P^2`, which is being used as a rigorous QFI upper relaxation.

## 3. Closed harmonic-oscillator formulas

Using

\[
N=\frac{X^2+P^2-1}{2},
\]

define

\[
\boxed{
\mu(s)=\sqrt{\vartheta(\vartheta-2s)}.
}
\]

A squeezing transformation gives

\[
\boxed{
Z_P(s)
=(1-e^{-\vartheta})
\frac{e^{(\vartheta-\mu)/2}}
{1-e^{-\mu}}.
}
\]

The tilted second moment is

\[
M_P(s)
=\partial_s\ln Z_P(s)
\]

or explicitly

\[
\boxed{
M_P(s)
=\frac{\vartheta}{2\mu}
\coth\frac\mu2.
}
\]

The relative entropy of the tilted optimizer is

\[
\boxed{
D_P(s)
=sM_P(s)-\ln Z_P(s).
}
\]

For every `D_0>0`, the active optimum is obtained by choosing the unique `s` on the increasing branch satisfying

\[
D_P(s)=D_0.
\]

Thus the global arbitrary-state QFI obeys the parametric ceiling

\[
\boxed{
J_F^{\max}(D_0,\vartheta)
\le
J_{P^2}(D_0,\vartheta)
\equiv
4M_P(s_{D_0})
=
\frac{2\vartheta}{\mu}
\coth\frac\mu2.
}
\]

**Status:** PROVED for arbitrary pointer states.

## 4. Relation to the exact global dual

`WP8_EXACT_GLOBAL_DUAL_CHARACTERIZATION.md` gives

\[
J_F^{\max}
=
\sup_L\inf_{\lambda>0}
\lambda\left[
D_0+\ln\operatorname{Tr}
 e^{\log\tau+K_L/\lambda}
\right],
\]

with

\[
K_L=2i[P,L]-L^2.
\]

There is an exact operator identity

\[
\boxed{
4P^2-K_L
=(L+2iP)^\dagger(L+2iP)
\succeq0.
}
\]

Hence

\[
K_L\preceq4P^2
\]

for every Hermitian `L`.

The direct-generator envelope can therefore also be read as an immediate relaxation of the exact global dual: replace every `K_L` by the common operator upper bound `4P^2`.

This explains both its rigor and why it need not be tight.

## 5. Equilibrium and asymptotic limits

At `D_0=0`, `s=0`, `mu=vartheta`, so

\[
J_{P^2}(0,\vartheta)
=2\coth\frac\vartheta2.
\]

The true equilibrium thermal QFI is

\[
J_\beta=2\tanh\frac\vartheta2,
\]

so the generator-moment relaxation is loose near high-temperature equilibrium. Use the exact thermal theorem there.

At large `D_0`, `mu -> 0` and

\[
D_P
=\frac{\vartheta^2}{2\mu^2}+O(|\ln\mu|),
\]

\[
J_{P^2}
=\frac{4\vartheta}{\mu^2}+O(1).
\]

Therefore

\[
\boxed{
J_{P^2}(D_0,\vartheta)
=\frac{8D_0}{\vartheta}
+O(\ln D_0).
}
\]

The exact even-parity construction has the same leading asymptotic behavior, so this direct generator bound independently confirms asymptotic global optimality of the parity branch to leading relative order.

## 6. Stronger arbitrary-state photodetection closure

The directional SLD-Stam theorem gives

\[
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{\tau J_D}
{2(1-\tau)+\tau J_D}.
\]

Using the direct-generator free-energy ceiling,

\[
J_D\le J_{P^2}(D_0,\vartheta),
\]

we obtain

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{
\tau J_{P^2}(D_0,\vartheta)
}{
2(1-\tau)+
\tau J_{P^2}(D_0,\vartheta)
}.
}
\]

With `tau<=sin^2 Gamma`, substitute the action cap on the right-hand side.

This is generally tighter than the earlier route based only on the maximum mean excitation `N_+(D_0,vartheta)`. For rigorous numerical work, take the minimum of all available upper envelopes, including the exact equilibrium result at `D_0=0` and any future dual bounds.

---

## 7. Remaining gap

The exact QFI frontier remains below this generator-moment envelope at finite temperature because mixed states can have

\[
J_X(\rho)<4\operatorname{Var}(P).
\]

Closing that gap requires solving the exact SLD/free-energy dual, not merely optimizing a second moment.

Nevertheless, this note upgrades the globally valid WP8 free-energy closure and provides the correct large-resource asymptotic coefficient without the intermediate maximum-entropy/energy relaxation.
