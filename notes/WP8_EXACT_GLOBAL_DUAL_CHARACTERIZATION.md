# WP8 — Exact global dual characterization of the free-energy/QFI frontier

**Date:** 2026-08-20

## Purpose

The remaining WP8 problem is the exact arbitrary-state frontier

\[
J_F^{\max}(D_0)
=\sup_{\rho:\,D(\rho\Vert\tau)\le D_0}J_X(\rho)
\]

for SLD displacement QFI relative to a faithful thermal reference `tau`.

The Gaussian and parity constructions solve important restricted regimes but do not solve the finite-budget global problem. This note gives an **exact variational dual characterization** of the full frontier. It converts the state optimization into an optimization over the SLD trial observable plus one scalar Lagrange multiplier and supplies self-consistency equations for any true optimizer.

The finite-dimensional statement is rigorous as written. For the harmonic oscillator the same formulas hold under the standard domain conditions that all displayed exponential partition functions are finite; unbounded-operator technicalities must be retained explicitly in any formal publication proof.

---

## 1. Variational representation of SLD displacement QFI

For translation generated by `P`,

\[
\rho_\theta=e^{-i\theta P}\rho e^{i\theta P},
\qquad
\dot\rho=-i[P,\rho].
\]

SLD QFI has the exact variational form

\[
J_X(\rho)
=\sup_{L=L^\dagger}
\left\{
2\operatorname{Tr}(\dot\rho L)
-\operatorname{Tr}(\rho L^2)
\right\}.
\]

Using cyclicity,

\[
2\operatorname{Tr}(\dot\rho L)
=2i\operatorname{Tr}[\rho(P L-LP)].
\]

Define

\[
\boxed{
K_L
=2i[P,L]-L^2.
}
\]

Then

\[
\boxed{
J_X(\rho)
=\sup_{L=L^\dagger}
\operatorname{Tr}(\rho K_L).
}
\]

At an optimum `L` this variational condition reproduces the SLD equation.

---

## 2. Relative-entropy expectation dual

For any Hermitian observable `K`, faithful reference state `tau`, and budget `D_0>0`, the exact constrained expectation problem

\[
\Phi_K(D_0)
=\sup_{\rho:\,D(\rho\Vert\tau)\le D_0}
\operatorname{Tr}(\rho K)
\]

has the Lagrange dual

\[
\boxed{
\Phi_K(D_0)
=
\inf_{\lambda>0}
\lambda\left[
D_0+
\ln\operatorname{Tr}
\exp\!\left(
\log\tau+\frac{K}{\lambda}
\right)
\right].
}
\]

This follows from the quantum Gibbs variational principle

\[
\sup_\rho
\left[
\operatorname{Tr}(\rho K)
-\lambda D(\rho\Vert\tau)
\right]
=
\lambda\ln\operatorname{Tr}
\exp\!\left(
\log\tau+\frac{K}{\lambda}
\right),
\]

plus strong duality. In finite dimension, `tau` itself is a strict feasible point whenever `D_0>0`, so Slater's condition holds.

At `D_0=0`, the formula is recovered as the `lambda -> infinity` limit and the only feasible state is `tau`.

## 3. Exact global WP8 dual

Because both optimizations are suprema,

\[
\sup_\rho\sup_L=\sup_L\sup_\rho.
\]

Combining Secs. 1 and 2 gives

\[
\boxed{
J_F^{\max}(D_0)
=
\sup_{L=L^\dagger}
\inf_{\lambda>0}
\lambda\left[
D_0+
\ln\operatorname{Tr}
\exp\!\left(
\log\tau+
\frac{2i[P,L]-L^2}{\lambda}
\right)
\right].
}
\]

This is an **exact characterization of the arbitrary-state free-energy/QFI frontier**.

No Gaussian, parity, Fock-diagonal, purity, or finite-rank assumption is made.

**Status:** PROVED in finite dimension; oscillator extension valid subject to stated domain/partition-function conditions.

## 4. Self-consistent optimizer equations

Suppose an interior finite-dimensional optimum is attained at `(rho_*,L_*,lambda_*)` with active resource constraint. Variation over `rho` gives

\[
\boxed{
\rho_*
=
\frac{
\exp\!\left[
\log\tau+
K_{L_*}/\lambda_*
\right]
}{
\operatorname{Tr}
\exp\!\left[
\log\tau+
K_{L_*}/\lambda_*
\right]
}.
}
\]

Variation over `L` gives

\[
\boxed{
\frac12\{\rho_*,L_*\}
=-i[P,\rho_*],
}
\]

so `L_*` is exactly the SLD of the optimum state.

The active constraint gives

\[
\boxed{
D(\rho_*\Vert\tau)=D_0.
}
\]

Thus the global optimum satisfies the nonlinear fixed-point system

\[
\boxed{
\begin{cases}
\rho\propto
\exp[\log\tau+(2i[P,L]-L^2)/\lambda],\\[3pt]
\{\rho,L\}/2=-i[P,\rho],\\[3pt]
D(\rho\Vert\tau)=D_0.
\end{cases}
}
\]

This system is a substantially sharper formulation of the previously informal 'two-parity interpolation' problem.

## 5. Relation to the Gaussian branch

Near thermal equilibrium,

\[
L_\beta=2\tanh(\vartheta/2)X
\]

is linear in `X`, so

\[
K_{L_\beta}
=\text{const}-cX^2
\]

is quadratic. The Gibbs state in the first fixed-point equation is therefore Gaussian. This reproduces `WP8_LOCAL_GAUSSIAN_OPTIMALITY.md` directly from the exact dual framework.

As the budget grows, a globally optimal `L` need no longer remain linear, and the induced state need no longer remain Gaussian. The analytic parity counterexample proves that such a departure eventually occurs for the explicit `vartheta=ln2` example.

---

## 6. Relation to the parity branch

If a trial SLD `L` is parity odd,

\[
\Pi L\Pi=-L,
\]

then both

\[
2i[P,L]
\]

and

\[
L^2
\]

are parity even. Hence `K_L` commutes with parity and the corresponding Gibbs state in the dual is parity block diagonal.

Both the local Gaussian optimum and the known parity-enhanced constructions lie naturally in this parity-odd-SLD / parity-even-state branch.

However, no proof has yet been obtained that a globally optimal `L` can always be chosen parity odd. The full exact dual therefore remains broader than the two-parity block-diagonal problem.

**Status:** structural observation PROVED; global parity-reduction conjecture OPEN.

## 7. Exact QFI penalty for a parity-block-diagonal state

Let

\[
\rho=p\rho_e\oplus(1-p)\rho_o
\]

with normalized even/odd states `rho_e,rho_o`. Diagonalize them as

\[
\rho_e=\sum_i a_i|e_i\rangle\langle e_i|,
\qquad
\rho_o=\sum_j b_j|o_j\rangle\langle o_j|.
\]

Since `P` flips parity, the exact SLD QFI is

\[
\boxed{
J_X(\rho)
=4\sum_{ij}
\frac{(p a_i-(1-p)b_j)^2}
{p a_i+(1-p)b_j}
|\langle e_i|P|o_j\rangle|^2.
}
\]

Using

\[
\frac{(x-y)^2}{x+y}
=x+y-rac{4xy}{x+y},
\]

this becomes

\[
\boxed{
J_X(\rho)
=4\langle P^2\rangle_\rho
-16\sum_{ij}
\frac{p(1-p)a_i b_j}
{p a_i+(1-p)b_j}
|\langle e_i|P|o_j\rangle|^2.
}
\]

The second term is a manifestly nonnegative **cross-parity mixing penalty**.

Consequences:

- a single-parity state has zero penalty and `J=4<P^2>`;
- populating both parity sectors can save free energy/entropy but generally reduces QFI at fixed second moment;
- the exact finite-budget optimum is a competition between these two effects.

This gives the precise mathematical content of the 'two-parity interpolation' problem.

## 8. Relative entropy decomposes exactly across parity sectors

Because the thermal reference is parity block diagonal,

\[
\tau=p_\beta\tau_e\oplus(1-p_\beta)\tau_o,
\]

with

\[
p_\beta=\frac1{1+e^{-\vartheta}},
\]

a parity-block-diagonal state obeys

\[
\boxed{
D(\rho\Vert\tau)
=
D_{\rm bin}(p\Vert p_\beta)
+pD(\rho_e\Vert\tau_e)
+(1-p)D(\rho_o\Vert\tau_o).
}
\]

Thus parity bias has an explicit binary-relative-entropy cost, while internal preparation costs add conditionally within each sector.

Together with Sec. 7, this reduces the parity-block problem to a transparent trade:

\[
\text{binary parity bias + within-sector preparation}
\quad\leftrightarrow\quad
\text{cross-parity QFI penalty + generator variance}.
\]

## 9. Odd-sector exact restricted frontier

The same linearization used for the even sector applies to states supported entirely in odd parity. The exact optimizer is

\[
\rho_{o,s}
\propto
\Pi_o e^{\log\tau+sP^2}\Pi_o.
\]

With

\[
\mu=\sqrt{\vartheta(\vartheta-2s)},
\]

its partition function is

\[
\boxed{
Z_o(s)
=(1-e^{-\vartheta})
\frac{e^{(\vartheta-3\mu)/2}}
{1-e^{-2\mu}}.
}
\]

The exact second moment is

\[
\boxed{
m_o(s)
=\frac{\vartheta}{\mu}
\left[
\frac32+
\frac{2}{e^{2\mu}-1}
\right],
}
\]

so

\[
\boxed{
J_o(s)=4m_o(s),
\qquad
D_o(s)=s m_o(s)-\ln Z_o(s).
}
\]

At `s=0`, the odd-sector entry cost is

\[
D_o(0)=\ln(1+e^{\vartheta}),
\]

which exceeds the even-sector entry cost

\[
D_e(0)=\ln(1+e^{-\vartheta})
\]

for every positive temperature parameter `vartheta>0`.

**Status:** PROVED exact odd-sector restricted frontier.

## 10. What the exact dual resolves and what remains open

Resolved:

1. The arbitrary-state free-energy/QFI frontier has an exact variational characterization.
2. Any optimizer satisfies explicit nonlinear SLD/Gibbs self-consistency equations.
3. The parity-block problem has an exact mixing-penalty formula and exact relative-entropy decomposition.
4. Both pure parity-sector restricted frontiers are analytically solved.

Still open:

1. Prove or disprove that the global optimum may always be chosen parity block diagonal / with parity-odd SLD.
2. Solve the finite-budget parity-block interpolation including the exact mixing penalty.
3. Determine the location and nature of the Gaussian-to-non-Gaussian crossover for a given `vartheta`.
4. Establish whether the global optimizer is unique and full rank at finite `D_0` in the infinite-dimensional oscillator.

The next mathematical route should use the exact dual/self-consistency system rather than unrestricted state guessing.
