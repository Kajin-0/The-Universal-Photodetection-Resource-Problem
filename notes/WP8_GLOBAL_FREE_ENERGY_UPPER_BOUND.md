# WP8 — Global arbitrary-state free-energy upper bound

**Date:** 2026-08-20

## Purpose

`WP8_NON_GAUSSIAN_PARITY_COUNTEREXAMPLE.md` proves that the exact Gaussian free-energy frontier is not globally optimal. Nevertheless, a finite nonequilibrium free-energy budget **does** impose a rigorous finite SLD displacement-QFI ceiling for arbitrary pointer states.

This note derives that global closure. It is not generally tight, but it is architecture-independent within the single harmonic pointer Hamiltonian and is sufficient to prove that finite preparation free energy repairs the hidden-pointer-resource loophole.

---

## 1. Thermal reference and free-energy constraint

Let

\[
\tau_\vartheta=(1-e^{-\vartheta})e^{-\vartheta N},
\qquad
\vartheta=\beta\hbar\omega_D>0.
\]

For an arbitrary detector pointer state `rho`, define

\[
D_0
= D(\rho\Vert\tau_\vartheta)
=\beta\Delta F_\beta(\rho).
\]

If

\[
\bar N=\operatorname{Tr}(\rho N),
\]

then

\[
D(\rho\Vert\tau_\vartheta)
=\vartheta\bar N
- S(\rho)
-\ln(1-e^{-\vartheta}).
\]

---

## 2. Free energy globally bounds the mean excitation

For one bosonic mode with mean excitation `N`, the maximum possible von Neumann entropy is the thermal entropy

\[
g(N)
=(N+1)\ln(N+1)-N\ln N.
\]

Thus

\[
S(\rho)\le g(\bar N).
\]

Therefore

\[
D_0
\ge
d_\vartheta(\bar N),
\]

where

\[
\boxed{
d_\vartheta(N)
=\vartheta N
- g(N)
-\ln(1-e^{-\vartheta}).
}
\]

The function `d_vartheta(N)` is minimized at the thermal occupation

\[
n_\beta=\frac1{e^\vartheta-1}
\]

with minimum zero and increases strictly for `N>n_beta`.

Define `N_+(D_0,vartheta)` as the largest nonnegative solution of

\[
\boxed{
d_\vartheta(N_+)=D_0.}
\]

Then every admissible pointer obeys

\[
\boxed{
\bar N\le N_+(D_0,\vartheta).
}
\]

This is a completely general consequence of the Gibbs maximum-entropy principle.

**Status:** PROVED.

---

## 3. Mean excitation globally bounds displacement QFI

For translation generated by `P`, SLD QFI satisfies

\[
J_X(\rho)\le4\operatorname{Var}_\rho(P).
\]

A parameter-independent phase-space displacement can remove pointer means without changing `J_X` and can only reduce the excitation resource required for the same centered state. Hence an optimum may be assumed centered.

For a centered state,

\[
\operatorname{Var}(X)+\operatorname{Var}(P)
=2\bar N+1.
\]

Robertson uncertainty gives

\[
\operatorname{Var}(X)\operatorname{Var}(P)
-\operatorname{Cov}(X,P)^2
\ge\frac14.
\]

Maximizing `Var(P)` at fixed `N` yields

\[
\operatorname{Var}(P)
\le
N+\frac12+\sqrt{N(N+1)}.
\]

Thus

\[
\boxed{
J_X(\rho)
\le
4N+2+4\sqrt{N(N+1)}.
}
\]

Define

\[
\xi(N)
=(\sqrt{N+1}-\sqrt N)^2.
\]

Since

\[
4N+2+4\sqrt{N(N+1)}
=\frac{2}{\xi(N)},
\]

we have

\[
\boxed{
J_X(\rho)\le\frac2{\xi(N)}.
}
\]

Combining with the free-energy excitation bound gives the global resource frontier ceiling

\[
\boxed{
J_F^{\max}(D_0,\vartheta)
\le
\frac{2}{\xi[N_+(D_0,\vartheta)]}.
}
\]

**Status:** PROVED for arbitrary pointer states.

This bound is generally not tight because the maximum-entropy state at fixed `N` and the maximum-QFI state at fixed `N` are different states.

## 4. Globally valid photodetection QFI-transfer theorem

`WP8_SLD_STAM_GLOBAL_ENERGY_THEOREM.md` proves that for a coherent optical displacement mixed passively into a detector pointer with source-to-detector probability `tau`,

\[
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{\tau J_B}
{2(1-\tau)+\tau J_B},
\]

where `J_B` is the pointer's directional SLD translation QFI before interaction.

Using the global free-energy ceiling above,

\[
J_B
\le
\frac2{\xi(N_+)},
\]

we obtain

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{\tau}
{\tau+(1-\tau)\xi[N_+(D_0,\vartheta)]}.
}
\]

This theorem is valid for **arbitrary, including non-Gaussian, pointer states** under the passive-linear single-collective-mode model.

If the source-detector coupling action satisfies

\[
\tau\le\sin^2\Gamma,
\qquad
\Gamma=\int_0^t\|V(s)\|_2ds,
\]

then

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{\sin^2\Gamma}
{\sin^2\Gamma+
\cos^2\Gamma\,\xi[N_+(D_0,\vartheta)]}.
}
\]

This is the first fully global finite-temperature preparation-resource closure of the WP7 coherent-state quantum branch.

**Status:** PROVED under the passive-linear coherent-displacement model assumptions.

## 5. Necessary coupling action for target information fraction

To achieve

\[
F_{\rm elec}/F_{\rm in}\ge q,
\qquad 0<q<1,
\]

a necessary condition is

\[
\boxed{
\Gamma
\ge
\arctan
\sqrt{
\frac{q\,\xi[N_+(D_0,\vartheta)]}
{1-q}
}.
}
\]

Equivalently, finite apparatus free energy and finite interaction action cannot be traded away simultaneously.

---

## 6. Large-free-energy asymptotics

For large `N`,

\[
g(N)=\ln N+1+O(N^{-1}),
\]

so

\[
d_\vartheta(N)
=\vartheta N-\ln N
-1-\ln(1-e^{-\vartheta})+o(1).
\]

Hence

\[
N_+(D_0,\vartheta)
=\frac{D_0}{\vartheta}
+O\!\left(\frac{\ln D_0}{\vartheta}\right).
\]

Also

\[
\xi(N)=\frac1{4N}+O(N^{-2}).
\]

For small interaction action `Gamma` and fixed target fraction `q`, the necessary condition therefore implies the asymptotic resource scaling

\[
\boxed{
D_0
\gtrsim
\frac{\vartheta q}
{4(1-q)\Gamma^2}
}
\]

up to logarithmic corrections.

In dimensional form,

\[
\boxed{
\Delta F_\beta
\gtrsim
\frac{\hbar\omega_D}{4}
\frac{q}{1-q}
\frac1{\Gamma^2}
}
\]

at leading order.

Thus the earlier `Delta F = Omega(Gamma^{-2})` conclusion survives globally, even after the Gaussian-optimality conjecture is rejected.

## 7. What remains open

The existence of a finite global free-energy bound is now solved. What remains open is the **tight** arbitrary-state frontier

\[
J_F^{\max}(D_0,\vartheta).
\]

We now know:

- the squeezed-thermal Gaussian frontier is not globally optimal;
- the parity/squeezed-parity family gives explicit non-Gaussian lower bounds;
- the excitation-envelope theorem in this note gives a rigorous global upper bound.

The exact frontier lies between these constructions.

A likely next route is to exploit the exact Fock-diagonal QFI functional and parity structure, rather than assuming Gaussian extremality.
