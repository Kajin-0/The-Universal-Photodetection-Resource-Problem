# WP7 — General apparatus QFI transfer bound under passive linear coupling

**Date:** 2026-08-19

## Scope

This note generalizes the energy-repaired coherent-state QFI result beyond Gaussian detector pointer states. The result is looser than the tight single-mode Gaussian theorem but applies to arbitrary detector-side quantum states under passive linear mode coupling.

The key invariant is the detector's pre-existing **translation susceptibility**, equivalently the largest variance of a normalized collective quadrature that can become conjugate to the transferred optical displacement.

---

# 1. Model

The optical source contains a coherent displacement parameter. Choose quadrature normalization

\[
[x,p]=i,
\qquad V_{\rm vac}=I/2.
\]

For a source coherent state whose mean `x` is `theta`,

\[
F_{\rm in}=2.
\]

Let the complete detector-side bosonic apparatus be in an arbitrary theta-independent state `sigma_D`; it need not be Gaussian.

The source and detector modes interact through an arbitrary passive number-conserving linear optical unitary. Let `tau` be the fraction of the source displacement amplitude norm transferred into the detector mode subspace. The subspace-transfer theorem gives

\[
\tau\le\sin^2\Gamma,
\qquad
\Gamma=\int_0^t\|V(s)\|_2ds,
\]

for `0<=Gamma<=pi/2`.

---

# 2. Detector family is a displacement family for arbitrary apparatus state

A passive linear unitary maps displacement operators to displacement operators. Therefore, after removing theta-independent coherent offsets, the reduced detector family has the form

\[
\rho_D(\theta)
=e^{-i\sqrt\tau\,\theta P_c}
\rho_D(0)
 e^{+i\sqrt\tau\,\theta P_c},
\]

where `P_c` is a normalized collective detector quadrature conjugate to the transferred displacement direction.

This statement does not require `rho_D(0)` to be Gaussian.

For any unitary parameter family generated by `G`, SLD QFI satisfies

\[
F_Q(\rho,G)\le4\operatorname{Var}_\rho(G).
\]

Hence

\[
\boxed{
F_D\le4\tau\operatorname{Var}_{\rho_D(0)}(P_c).
}
\]

Any electrical readout is downstream of the detector state, so

\[
F_{\rm elec}\le F_D.
\]

---

# 3. Apparatus translation-susceptibility resource

Define

\[
\boxed{
\mathcal R_D
\equiv
2\sup_{c}\operatorname{Var}_{\rho_D(0)}(P_c),
}
\]

where the supremum runs over normalized collective detector modes/quadrature directions accessible to the passive coupling and detector-local passive processing.

Vacuum/coherent states have

\[
\mathcal R_D=1.
\]

Since `F_in=2`,

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\min\{1,\tau\mathcal R_D\}.
}
\]

Using the coupling-action ceiling,

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\min\{1,\mathcal R_D\sin^2\Gamma\}.
}
\]

This is the broadest coherent-source QFI interaction theorem currently obtained in WP7.

**Status:** PROVED for coherent displacement encoding + passive linear coupling + arbitrary theta-independent detector-side quantum state, with `R_D` defined as above.

---

# 4. Total excitation-energy corollary

Suppose the theta-independent fluctuation state of all detector pointer modes has total mean excitation

\[
N_{\rm tot}\le N.
\]

For any normalized collective detector mode `c`, its excitation satisfies

\[
n_c\le N.
\]

Let its quadratures be `X_c,P_c`. After removing theta-independent means,

\[
\operatorname{Var}(X_c)+\operatorname{Var}(P_c)
=2n_c+1
\le2N+1.
\]

Robertson uncertainty gives

\[
\operatorname{Var}(X_c)\operatorname{Var}(P_c)
\ge1/4.
\]

For fixed sum `<=2N+1`, the maximum possible single-quadrature variance is

\[
\boxed{
V_{\max}(N)
=N+\frac12+\sqrt{N(N+1)}.
}
\]

Therefore

\[
\mathcal R_D
\le
2V_{\max}(N)
=2N+1+2\sqrt{N(N+1)}.
\]

Using

\[
\xi(N)=(\sqrt{N+1}-\sqrt N)^2,
\]

we have the identity

\[
2N+1+2\sqrt{N(N+1)}=\frac1{\xi(N)}.
\]

Hence

\[
\boxed{
\mathcal R_D\le\frac1{\xi(N)}.
}
\]

The resulting broad energy-constrained theorem is

\[
\boxed{
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\min\left[
1,
\frac{\tau}{\xi(N)}
\right]
\le
\min\left[
1,
\frac{\sin^2\Gamma}{\xi(N)}
\right].
}
\]

**Status:** PROVED under the total excitation budget and passive linear coupling assumptions.

---

# 5. Necessary coupling action

To transfer a target fraction `q` of the coherent input QFI, the broad theorem requires

\[
\sin^2\Gamma\ge q\,\xi(N),
\]

so

\[
\boxed{
\Gamma\ge\arcsin\sqrt{q\,\xi(N)}.
}
\]

If `||V(t)||<=g_max`, then

\[
\boxed{
t\ge\frac1{g_{\max}}\arcsin\sqrt{q\,\xi(N)}.}
\]

For large `N`,

\[
\xi(N)\sim\frac1{4N},
\]

and therefore

\[
\Gamma_{\min}\gtrsim\sqrt{\frac{q}{4N}}.
\]

This has the same `N^{-1/2}` asymptotic resource scaling as the tight Gaussian theorem, although the coefficient and high-q behavior are looser.

---

# 6. Comparison with the tight Gaussian theorem

For a single effective Gaussian detector mode, the stronger exact bound is

\[
\frac{F_{\rm elec}}{F_{\rm in}}
\le
\frac{\tau}{\tau+(1-\tau)\xi(N)}.
\]

The general apparatus theorem gives only

\[
\frac{F_{\rm elec}}{F_{\rm in}}
\le\min[1,\tau/\xi(N)].
\]

The gap comes from replacing exact Gaussian displacement QFI by the universal inequality

\[
F_Q\le4\operatorname{Var}(G).
\]

Closing this gap for arbitrary multimode/non-Gaussian apparatus is OPEN.

---

# 7. Why `R_D` is a useful resource variable

An initial-energy budget is physically intuitive but model dependent when detector modes have different frequencies or are not literal optical oscillators.

The translation resource

\[
\mathcal R_D=2\sup\operatorname{Var}(P_c)
\]

is more operational:

- it is dimensionless in normalized oscillator units;
- it directly quantifies how sharply the apparatus can resolve a displacement after weak coupling;
- it makes the squeezed-pointer counterexample transparent;
- it can later be bounded by energy/free energy/ergotropy for a specified detector Hamiltonian.

It is not the photodetection performance metric itself and therefore does not simply restate the bandwidth being bounded.
