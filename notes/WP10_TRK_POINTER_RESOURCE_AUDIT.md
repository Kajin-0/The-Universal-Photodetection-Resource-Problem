# WP10 — TRK/f-sum audit for the detector-pointer microscopic resource

**Date:** 2026-08-20

## Purpose

WP8 identifies a missing quantum apparatus resource: finite free energy and even complete energy-population information do not prevent arbitrarily high-energy coherences from exploiting an unbounded displacement generator. A finite support/generator-capacity bound repairs the problem mathematically.

This note tests whether the Thomas–Reiche–Kuhn (TRK) / oscillator-strength sum rule can provide the required microscopic bound from matter physics.

Main conclusion:

> **TRK alone does not bound the relevant generator scale for arbitrary excited/non-equilibrium pointer states. Its signed excited-state structure admits exact cancellation loopholes. A positive bound requires an additional spectral/support condition (or a stronger unsigned microscopic resource).**

---

# 1. One-particle TRK identity

For

\[
H=\frac{p^2}{2m}+V(x),
\qquad[x,p]=i\hbar,
\]

the double commutator gives

\[
[x,[H,x]]=\frac{\hbar^2}{m}.
\]

For an exact energy eigenstate `|n>`, inserting completeness yields

\[
\boxed{
\sum_m(E_m-E_n)|x_{nm}|^2
=\frac{\hbar^2}{2m}.
}
\]

Define the signed oscillator strength

\[
\boxed{
f_{nm}
=\frac{2m}{\hbar^2}(E_m-E_n)|x_{nm}|^2.}
\]

Then

\[
\boxed{\sum_m f_{nm}=1.}
\]

For a ground state all allowed final-state energy differences are nonnegative. For an excited state, downward transitions have

\[
f_{nm}<0.
\]

Thus the positive upward oscillator-strength sum is not bounded by 1; negative downward terms can cancel arbitrarily large positive upward terms.

This signed structure is standard oscillator-strength physics. See Z. Hens, Chem. Phys. Lett. 463, 391–395 (2008), DOI `10.1016/j.cplett.2008.08.089`, which explicitly discusses oscillator strengths exceeding unity for excited-state transitions and the role of negative downward strengths.

# 2. Exact harmonic-oscillator counterexample

Take

\[
H=\hbar\omega(N+1/2).
\]

The position matrix elements are

\[
|x_{n,n+1}|^2
=\frac{\hbar}{2m\omega}(n+1),
\]

\[
|x_{n,n-1}|^2
=\frac{\hbar}{2m\omega}n.
\]

Therefore

\[
\boxed{f_{n,n+1}=n+1,}
\]

\[
\boxed{f_{n,n-1}=-n.}
\]

The TRK identity remains exactly satisfied:

\[
(n+1)-n=1.
\]

Yet the upward oscillator strength diverges:

\[
f_{n,n+1}\to\infty.
\]

The momentum matrix element also diverges:

\[
|p_{n,n+1}|^2
=\frac{m\hbar\omega}{2}(n+1).
\]

Hence

\[
\boxed{
\text{TRK sum fixed}
\quad\not\Rightarrow\quad
\text{bounded high-level transition/generator matrix elements}.
}
\]

This is exactly the microscopic algebra behind the WP8 UV coherence loophole.

**Status:** PROVED explicit counterexample.

# 3. Why an excited-state f-sum cannot replace the support resource

Suppose one attempts to bound detector-pointer displacement QFI using only a TRK constant such as electron number.

For an excited pointer state, the signed identity has the schematic form

\[
S_+-S_-=N_e,
\]

where `S_+` is total upward oscillator strength and `S_-` is the magnitude of downward strength.

Nothing prevents

\[
S_+\to\infty,
\qquad
S_-\to\infty,
\qquad
S_+-S_-=N_e.
\]

Thus the signed sum controls a difference, not the absolute transition budget needed to regularize the pointer metrological generator.

A valid universal repair would need, for example,

- an **unsigned** oscillator-strength budget;
- a bound on downward oscillator strength;
- bounded excitation number/support;
- finite spectral span;
- saturation/finite participating degrees of freedom;
- or direct bounds on the relevant generator matrix elements.

# 4. Positive ground-state / no-downward-transition theorem

The TRK identity does become a useful positive resource if all relevant energy differences have one sign.

Assume the pointer preparation is a state `|0>` with no dipole-allowed lower-energy states, so

\[
E_m-E_0\ge0
\]

for all matrix elements appearing in the sum.

Then

\[
\sum_m(E_m-E_0)|x_{0m}|^2
=\frac{\hbar^2}{2m}
\]

is a positive budget.

The momentum matrix elements obey

\[
p_{0m}
=\frac{im}{\hbar}(E_0-E_m)x_{0m}.
\]

If, in addition, the relevant dipole-connected spectrum obeys

\[
0\le E_m-E_0\le\Delta E_{\max},
\]

then

\[
\sum_m|p_{0m}|^2
=
\frac{m^2}{\hbar^2}
\sum_m(E_m-E_0)^2|x_{0m}|^2
\]

\[
\le
\frac{m^2\Delta E_{\max}}{\hbar^2}
\sum_m(E_m-E_0)|x_{0m}|^2
\]

and therefore

\[
\boxed{
\operatorname{Var}_{0}(p)
\le
\frac{m\Delta E_{\max}}{2}.
}
\]

For a physical translation `x_s` generated by

\[
U(x_s)=e^{-ix_sp/\hbar},
\]

the pure-state QFI is

\[
F_{x_s}=\frac{4\operatorname{Var}(p)}{\hbar^2}.
\]

Hence

\[
\boxed{
F_{x_s}
\le
\frac{2m\Delta E_{\max}}{\hbar^2}.
}
\]

So TRK gives a finite pointer metrological scale only after an additional maximum spectral-energy resource is specified.

# 5. Many-electron extension

For `N_e` ordinary electrons with total coordinate

\[
X=\sum_{j=1}^{N_e}x_j
\]

and a standard position-dependent interaction Hamiltonian, the many-electron double commutator gives

\[
\sum_m(E_m-E_0)|X_{0m}|^2
=\frac{N_e\hbar^2}{2m_e}.
\]

Let the corresponding total canonical momentum be

\[
P=\sum_jp_j.
\]

For a ground/no-downward-transition preparation and a maximum relevant transition energy `Delta E_max`, the same argument gives

\[
\boxed{
\operatorname{Var}_0(P)
\le
\frac{N_em_e\Delta E_{\max}}{2}.
}
\]

Therefore the spatial-translation QFI obeys

\[
\boxed{
F_x^Q
\le
\frac{2N_em_e\Delta E_{\max}}{\hbar^2}.
}
\]

This provides a genuine matter-side microscopic completion for a restricted low-excitation pointer class.

**Assumptions matter:** the positivity argument fails for generic excited/non-equilibrium preparations because of downward-transition cancellation.

# 6. Ground-state TRK alone is still not enough for momentum QFI

Even in the ground-state case, the TRK sum fixes

\[
\sum_m\Delta E_m|x_{0m}|^2,
\]

whereas momentum variance contains

\[
\sum_m\Delta E_m^2|x_{0m}|^2.
\]

Therefore a finite TRK constant without any upper spectral-energy scale does not by itself bound momentum variance.

This is why `Delta E_max` entered Secs. 4–5.

The resource pair is schematically

\[
\boxed{
\text{oscillator-strength budget}
+
\text{finite spectral span}
\Rightarrow
\text{bounded pointer translation QFI}.
}
\]

# 7. Important operator-identification warning

WP5 uses electromagnetic/matter oscillator-strength constraints to bound **optical capture**. WP8 uses a detector pointer generator `G` (for the harmonic model, a quadrature conjugate to the readout displacement) to bound **pre-existing apparatus metrological capacity**.

These need not be the same operator or degree of freedom.

Therefore one must not silently reuse the WP5 optical TRK/T-operator budget as the WP8 pointer regularizer. Doing so would double-count or conflate two physically distinct layers unless a microscopic detector model explicitly identifies them.

A complete semiconductor/device mapping must specify:

1. the optical dipole/current operator controlling photon capture;
2. the internal pointer/readout generator controlling electrical distinguishability;
3. the dynamical map connecting them.

Only then can one determine whether a common matter sum rule constrains both.
