## Mechanical failures found and repaired

### Failure 1 — REVTeX paragraph-column table

The original falsification table used `p{...}` columns inside REVTeX grid machinery. This produced fatal `Extra \\or` errors. Removing only `ruledtabular` did not solve it: REVTeX itself remained incompatible with the paragraph-column construction.

Decision: R1 replaces the table with ordinary paragraph blocks carrying the same scientific content.

### Failure 2 — REVTeX description labels

A description-list replacement also failed under the same REVTeX grid machinery (`Missing \\endcsname inserted`).

Decision: use no list/table environment for the falsification hierarchy; use conservative `\\noindent\\textbf{...}` paragraph headings.

### Failure 3 — stale byte offsets in the R1 transform

The first paragraph-block transform computed the `table*` byte slice, then shortened a preceding lead sentence, invalidating the slice. A fragment of the float survived and caused `Paragraph ended before \\@yfloat was complete`.

Repair commit: `d12306bd933122927530c9374eb6ff495038d608`.

The transformer now removes the float before changing any preceding text and rejects any residual `table*`, `tabular`, or `ruledtabular` markup in generated R1.
